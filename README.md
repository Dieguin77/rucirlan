# Rucirlan — Honório Consultor Multimarcas de Consórcios

Site institucional para consultor de consórcios, com foco em captação de leads via WhatsApp.

---

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

---

## Funcionalidades

- Formulário de simulação com captura de lead (nome, telefone, objetivo, faixa de crédito, melhor horário de contato)
- Envio direto para o WhatsApp do consultor, com mensagem pré-preenchida específica por modalidade (imóveis, veículos, motos, caminhões, consórcio empresarial)
- Carrossel de administradoras parceiras
- Seção de depoimentos de clientes
- Widget de chat flutuante do WhatsApp
- Design responsivo (mobile, tablet e desktop)
